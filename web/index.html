about zibs

A link shortener service for people who've said hi.
No accounts, no tracking, no costs.

// how do I use it?

You email zibs@dinubarbu.com and ask for a personal zib token. I'm sending it to you, then you can zib links with it.

// how long do short links last?

90 days from creation — after that the short URL returns 404. The expiry is fixed; if you need a link for longer, create it again.

// does my token expire?

No. A token stays valid indefinitely but is good for a limited number of uses (plenty). When it runs out, just ask for another.

// what does this page store about me?

Nothing. Your token travels only in the request header when creating a link — never in cookies or storage — and the short URL is shown exactly once.

// what runs this?

A Go backend with an observability stack around it. Both the general metrics dashboard and the source code are public.
